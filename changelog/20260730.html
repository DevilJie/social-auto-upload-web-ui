微信公众号视频发布 v1.2.4

打通公众号视频发布的完整两阶段流程:① 素材上传页上传视频 → 封面(16:9) → 标题 → 原创声明 → 服务规则 → 保存并发表;② 发布编辑页填标题/描述(含 # 标签) → 合集 → 创作来源 → 立即/定时发表(支持扫码确认)。覆盖公众号所有发布选项,token 动态解析、按钮 disabled 态轮询、弹窗确认等细节均已打磨。

两阶段流程 定时发布 原创声明 创作来源 合集 扫码确认
+

微信公众号图集(贴图)发布

创作中心首页点击「贴图」进入编辑页(type=77),多张图片一次性上传,标题(≤20字)、描述(≤1000字,含 # 标签)、贴图合集、创作来源、定时发布全支持。发表流程(含定时开关、二次确认、扫码等待)与视频完全一致,复用同一套发布逻辑。图集合集与视频合集数据来源分离(贴图合集 / 视频合集独立 tab)。

多图一次性上传 贴图合集 创作来源 定时发布
+

公众号合集数据来源接入

新增公众号合集列表抓取 API,打开合集管理页 → 点击「视频合集」或「贴图合集」tab → 解析表格获取合集数据。找不到对应 tab 时自动返回空(代表该账号无此类型合集),视频与图集合集互不干扰。

修复优化 · 5 项

微博关键修复 + 公众号细节打磨

✓

微博内容声明版本 2 选择不上

微博内容声明版本 2 的下拉选项点击不稳定,accessible name 定位方式在新版前端下失效,导致选项选不上。改为用 CSS 类 ``_optionLabel`` 定位选项文案再点父级按钮,并补全日志消灭静默吞异常,声明选择恢复稳定。

微博 内容声明 关键修复
✓

公众号发布前标题长度校验前置

公众号标题 ≤64 字的校验原来只在后端 /postVideo 发生(账号检查之后才拦),前端表单校验阶段直接放行。现前端 videoLimits 补全公众号规则,标题超长在账号检查前就被拦截,不再白跑账号检查。

微信公众号 表单校验
✓

账号检查弹窗公众号平台图标缺失

发布前账号检查弹窗里公众号只显示昵称,平台 logo 不显示。根因是平台 ID→Key 映射漏了 17(weixin_gzh),补全后图标正常显示。

微信公众号 账号检查
✓

发布历史 / 草稿箱公众号枚举遗漏

后端多处硬编码的平台 ID→名称映射漏了公众号(17),导致发布历史脏数据兜底、草稿箱渠道摘要里公众号显示异常。统一补全后发布历史与草稿箱的公众号显示正常。

发布历史 草稿箱 枚举补全
✓

图集定时发布时间发布时被清空

图集发布设定时时间后点发布,时间被清空导致变成立即发布。根因是图集 mergeConfig 合并 scheduleTime 时漏了 panelAccountOv 层级,修复后账号级定时时间在发布时不再丢失(该修复惠及所有图集平台)。

图集发布 定时发布 通用修复
