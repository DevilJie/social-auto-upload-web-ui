v1.2.6 是一次「发布效率」大版本 —— 发布中心新增批量视频发布:一次添加多条视频排队逐条自动发,配好一次全队生效,全程进度实时可见、随时可取消;视频号发布补齐关联剧集与文章 / 红包封面链接;同时修复了淘宝光合选品失败、抖音数据不全、CSDN 登录检测等一批问题,兼容性也更稳了。

一图速览本次 v1.2.6 的所有变化

批量视频发布 · 全新

发布中心新增视频队列:一次添加多条视频,排队逐条自动发布;一套设置可应用到全队,进度卡片实时刷新,中途随时取消剩余。

视频号剧集 + 链接

发布视频号视频可关联视频号剧集 / 小程序短剧(支持搜索翻页),也能挂公众号文章、红包封面链接,粘贴即自动填入,四选一全部可用。

新功能

淘宝光合发布时关联商品老是失败,根因是官方页面改版。已适配新版页面;即使关联商品偶尔失败,也不再卡住整个发布,视频照常发出去。

关键修复

多平台稳定性提升

CSDN 登录检测、抖音运营数据、B 站发布判定、公众号教育弹窗、多平台封面比例等一批问题修复,安装启动兼容 Python 3.9,老环境也能跑。

批量视频发布 v1.2.6

发布中心新增视频队列,一次把多条视频加入待发列表,系统逐条自动完成「上传 → 填表 → 发布」全流程。每条视频可单独调整内容,队列随时增删,不用再一条条手动点发布。

多视频排队 逐条自动发布 队列管理

全视频应用 + 重传自动重抽封面

改好的标题、标签、平台设置等可以一键「应用到全部视频」,不用逐条重复填;重新上传视频时会自动重新抽取封面,不用担心封面和新视频对不上。

发布进度卡片化,随时可取消

提交发布后弹出实时进度卡片,每条视频发到哪一步一目了然;支持「取消所有剩余」,点一下就停,不再只能干等。封面自动裁剪等耗时步骤也有状态提示。

实时进度 取消剩余 状态提示

视频号发布关联剧集

发布视频号视频时,可以从自己的剧库里挑选要关联的视频号剧集或小程序短剧:支持按名称搜索、翻页浏览,选中后发布时自动关联,授权信息自动带入。没有剧集权限的账号会立刻提示,不再傻等。

剧集搜索 翻页浏览 自动关联 无权限秒提示
+

公众号文章 / 红包封面链接自动设置

视频号「链接」四选一全部可用:公众号文章、红包封面只要粘贴对应链接,发布时自动选好类型并填入官方页面,不用再手动操作。之前这两项一直是占位,本次补齐。

粘贴即用 自动选择类型 自动填入

选品修复 失败降级 关键修复
