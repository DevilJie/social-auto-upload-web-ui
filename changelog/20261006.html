批量发布更聪明 · 发布结果更真实

v1.2.9 围绕「批量发布」做了一次体验翻新:批量设置新增作品声明与原创声明,一次勾选、全平台自动映射;发布前账号检查与发布确认两个弹窗彻底重构,每个问题都附带「怎么解决」的指引;小红书发布结果改为以页面「发布成功」为准——发布成功才算成功,验证扫码不限时;大鱼号直达发布页,不再依赖悬停菜单。

批量设置 · 作品声明与原创声明

各平台声明字段名五花八门,现在只需选择「不做声明 / AI生成」与「原创 / 非原创」,系统自动映射成每个平台自己的字段和文案——批量一次勾选,18 个平台全部生效。

核心升级

两个弹窗 · 彻底重构

发布前账号检查、批量发布确认两大弹窗重新设计:结论先行、问题内联、每个错误附带「怎么解决」的行动指引和完整受影响账号列表——不再有看不懂的「Cookie 失效」和被截断的「等 N 项」。

体验重构

发布结果 · 以「发布成功」为准

小红书发布判定重做:轮询页面「发布成功」文案,弹出验证时不限时等待人工扫码;点了发布但页面没成功,任务会如实标记失败——不再出现"假成功"。

行为修复

发布链路 · 适配平台改版

小红书封面弹窗适配新版触发方式(悬停封面 → 点「编辑封面」→ 上传后点「完成」),自动关闭「PK封面」新功能引导;大鱼号直达发布页,不再依赖悬停菜单的多步交互。

稳定性修复

「Cookie 失效」改为「登录已过期」;顶部结论横幅动态播报进度(「N 个账号登录已过期」→「已修复 X/Y」);每张卡片带状态胶囊(待处理 / 等待扫码登录 / 已修复 / 登录失败),失败时给出具体原因;已修复账号留在列表中直观呈现,正常账号默认折叠不再干扰。修复了登录成功后卡片从列表"跳走"导致进度看不清的问题。

批量发布确认弹窗重构

从「表格 + 隐藏展开行」改为「统计筛选胶囊 + 卡片流」:顶部一眼看出可发布/待处理数量,点击筛选只看对应视频;校验问题直接内联铺在卡片里,不用再找哪里点开;可发布的视频整卡点选;发布间隔设置从半屏警告框降为紧凑工具行,详细说明收进悬浮提示。

修复与优化 · 4 项

实测中发现并修复的问题

✓

修复:小红书"假成功"问题

此前点击发布后仅等 3 秒检查 URL,且判定结果被丢弃——即使页面报错,任务也标记成功。现改为持续轮询页面「发布成功」文案,URL 跳转作为兜底;弹出验证时不限时等待人工扫码确认;点击发布但始终未出现成功信号时,任务如实标记失败并注明失败账号。

假成功 → 真实结果 验证扫码不限时 逐账号上报
✓

适配:小红书封面弹窗新触发方式

小红书改版后封面编辑入口变化:现按新 UI 先悬停封面预览区(AI 封面布局容器)再点击「编辑封面」打开弹窗,上传图片后点击「完成」红色按钮确认;旧版选择器全部保留兜底,新旧界面都能正常设置封面。

悬停 → 编辑封面 完成按钮确认 旧 UI 兼容
✓

适配:小红书「PK封面」新功能引导

发布页新出现的「视频可以PK封面啦」引导弹窗会遮挡封面预览,导致悬停与点击失败。现检测到引导弹窗时自动点击「我知道了」关闭,等待退场动画结束后再继续封面设置;关闭失败不阻断发布流程。

自动关闭引导 不阻断发布
✓

优化:大鱼号直达发布页

发布入口从「创作中心首页 → 悬停发布内容 → 展开菜单 → 点击短视频」的多步交互,改为直接跳转视频发布页;打开后等待编辑区渲染完成再继续,未登录被重定向时明确报错并附带当前页面地址,排查更省心。

一步直达 加载确认 失败可诊断
