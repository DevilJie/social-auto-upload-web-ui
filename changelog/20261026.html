修复与优化 · 9 项

自动化可靠性与体验修复

✓

修复:百家号封面"假生效"

平台对 JS 合成点击不受理,且"裁剪处理中"未完成时点确定会被静默忽略——导致弹窗看似走完、封面实际丢失,发表时被平台以「请上传封面」拦截。现改为 locator 真实鼠标事件 + 稳定等待 + 落槽验证,未生效自动补点重试,全程步骤级日志。

真实鼠标事件 落槽验证 + 补点 卡死 15s 保护
✓

修复:CSDN 标签"假生效"

此前回车激活只写入隐藏表单域,未进编辑器数据——保存后标签丢失,平台自动补默认标签「技术分享」。现改为点选联想下拉中精确匹配项(真实 DOM 交互),无精确联想时才回车兜底;发草稿端到端验证标签完整落库。

点选联想精确项 草稿实测核对
✓

修复:悬停提示两主题配色反转

悬停 tooltip 在亮色模式显示白字、暗色模式显示黑字(Element Plus 用文字色当气泡背景,与本项目自定义变量叠加后两主题双双错位)。已在全局修正气泡配色,两主题均恢复正确对比度。

亮/暗双主题修复 全局一处生效
✓

修复:知乎图文发布系列问题

图文发布补齐全部「发布设置」并重做发表判定(清理覆盖残留);修复面板默认标题校验被覆盖导致误报「标题不能为空」;正文图片上传冷启动偶发超时,调整为 90s 超时 + 自动重试一次;定时发布后端已就绪(待平台日历控件自动化后启用)。

发表判定重做 超时自动重试 定时后端就绪
✓

优化:文章发布页交互细节

修复页面级滚动条与空数据提示样式;侧栏账号点击改为仅选中,不再误触移除勾选;移除直接发表的二次确认弹窗,确认文案按所选平台动态生成,少一步干扰、多一分明确。

布局修复 账号仅选中 确认文案动态化
✓

优化:B 站 / 数据源接口稳定性

B 站发布表单补齐参与话题、可见范围、互动设置、粉丝动态,合集/话题数据源重构为纯 HTTP 直连;重浏览器数据源接口统一增加 TTL 缓存,重复打开下拉不再重复起浏览器,响应更快。

B 站表单补齐 HTTP 直连重构 TTL 缓存提速
✓

修复:文章发布历史封面不显示

文章发布的历史记录里封面存于 coverStoredPath,而列表/详情两处渲染只认视频发布的封面字段——文章批次一律显示占位图。已在后端封面兜底链与详情页渲染中补齐该字段,文章发布历史的封面恢复正常显示。

列表 + 详情双修复 不影响视频字段
✓

优化:发布历史新增月视图入口

发布日历(只读月视图)此前是独立页面、入口不明显。现在发布历史页标题行右侧新增「月视图」按钮,一键跳转日历页,按月浏览全部发布记录。

历史 → 日历一键直达
