## 二、B 站发布 · 简介/描述

千帆云递 v1.2.6 正式发布,这次是个"效率大版本"!

🎬 批量视频发布
发布中心新增视频队列:一次添加多条视频,自动排队逐条发布;一套设置可一键应用到全队;进度卡片实时刷新,中途随时"取消所有剩余"。

📺 视频号「剧集 + 链接」全打通
发布视频号视频可关联视频号剧集 / 小程序短剧(支持搜索、翻页);公众号文章、红包封面链接粘贴即自动填入,四种链接类型全部可用。

🏷 B 站新开关:「保留系统生成标签」
默认开启保持原样;关闭后发布前自动清空 B 站生成的推荐标签,只留你自己写的标签,按账号独立设置。

🔧 一波修复
- 淘宝光合发布关联商品失败(已适配新版页面,失败自动降级不卡发布)
- 视频号「原创声明」设置不上(页面改版适配)
- 抖音/快手/微博/支付宝/百家号/公众号:描述为空不再自动把标题抄进去
- 发布后视频不再从队列消失,失败可直接重发
- CSDN 登录检测、抖音运营数据、多平台封面比例等细节修复
- 兼容 Python 3.9,老环境启动更稳
