# PR 标题

v1.2.6:批量视频发布 + 视频号剧集/链接 + B 站标签开关 + 发布取消机制修复

# PR 描述

## 概述

本 PR 包含 50 个提交,版本号升至 **1.2.6**(基线:v1.2.5 / master)。
主线是发布中心能力升级(批量发布、视频号关联能力)和发布任务队列的可靠性修复(取消机制)。

## ✨ 新功能

### 1. 批量视频发布
- 发布中心新增视频队列:一次添加多条视频,自动排队逐条发布,严格串行(单 worker),避免多浏览器并发触发平台风控
- 「全视频应用」:一套设置(标题/简介/标签/封面/平台特有字段)一键应用到队列全部视频
- 提交后实时进度弹窗:进度卡片化展示,支持单个取消和「取消所有剩余」

### 2. 视频号「关联剧集 + 链接」全链路
- 发布视频号视频可关联**视频号剧集 / 小程序短剧**:支持搜索、翻页,账号无权限时快速返回空态并禁用搜索
- 「链接」四选一全部可用:剧集 / 小程序短剧 / **公众号文章** / **红包封面**,粘贴链接后发布时自动选择类型并填入官方页面
- 剧集选择器常驻浏览器改为无头模式,链接设置提前到上传完成前处理,发布更快更稳

### 3. B 站「保留系统生成标签」开关
- 标签卡片新增开关,默认开启保持原样;关闭后发布前自动清空 B 站生成的推荐标签再填入自己的标签,按账号独立设置

### 4. 其它
- 发布历史卡片悬停改为灰色遮罩 + 居中操作按钮(删除/取消)
- 视频号发布默认改为真实发布(CHANNELS_DRY_RUN_PUBLISH=1 可切回模拟)

## 🛠 重要修复

### 发布取消机制(三轮修复)
- **取消不再并发开浏览器**:同步平台(视频号/B站/快手等)发布线程无法强杀,以前取消只是"不再等它",队列立刻放行启动下一个任务 → 多次取消变成所有平台浏览器同时发布;现在取消后等该线程收尾再放行,期间绝不启动新任务
- **批量取消一次请求**:新增 POST /api/v2/tasks/cancel-batch,前端不再逐个任务发请求
- **孤儿任务清理**:后端重启后 DB 里残留的 running/queued 任务以前永远显示"排队中"且取消报 400,现在启动即清理、取消接口 DB 兜底

### 平台适配与修复
- 淘宝光合:关联商品选品失败根因修复(switch_radio 改版容错)+ 失败自动降级不阻塞发布
- 视频号:原创声明适配新版 DOM;发布后表单内容保留
- 抖音/快手/微博/支付宝/百家号/公众号:视频描述为空不再自动回落成标题
- CSDN 登录检测适配新版创作者首页;抖音运营数据抓取不全(关注/粉丝丢失)
- 5 平台封面比例、B 站判定等待、公众号教育弹窗、全平台页关守卫
- 发布后视频保留在队列,不再自动移出

### 环境兼容
- 兼容 Python 3.9;venv Python 版本与系统不一致时自动重建
