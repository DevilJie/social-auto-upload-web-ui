## 1. 系统概述

**千帆云递**是一个多平台社媒内容一键分发桌面工具（Tauri 2 打包，Windows）：

```
桌面壳(Tauri/WebView2) → 前端(Vue3 + Element Plus, 端口 5173) → Flask 后端(端口 5409) → 平台自动化(Playwright + CloakBrowser 隐匿 Chromium)
```

**支持的平台**（覆盖视频 / 图文 / 文章三种内容形态）：

| 内容形态 | 平台 |
|---|---|
| 视频 | 小红书、视频号、抖音、快手、B站、百家号、TikTok、YouTube、腾讯视频、爱奇艺、微博、支付宝、今日头条、知乎、CSDN、VIVO、微信公众号、淘宝光合、京东京麦、大鱼号 |
| 图文（图集） | 小红书、抖音、快手、微博、支付宝、微信公众号 |
| 文章 | 微信公众号、知乎、CSDN、微博、百家号、大鱼号、今日头条 |

**左侧菜单总览**：

| 菜单 | 一句话定位 |
|---|---|
| 仪表盘 | 数据总览与快捷入口 |
| **账号管理** | 绑定与维护所有平台账号（一切功能的前提） |
| **素材管理** | 视频/图片素材统一仓库 |
| **视频发布** | 多平台多账号视频批量发布（核心页） |
| 图集发布 | 6 平台图文/图集发布 |
| **文章发布** | 7 平台文章发布（公众号/知乎/CSDN 等） |
| **草稿箱** | 三类草稿的集中管理与批量发布 |
| 发布历史 | 每次发布的任务结果与重试 |
| 更新日志 | 版本变化 |
| 关于作者 / 赞助作者 / 一键反馈 | 支持与反馈 |
| **系统设置** | 代理、发布偏好、存储、缓存等 |

**新用户推荐路线**：系统设置扫一眼（可全默认）→ 账号管理添加账号 → 素材管理传素材 → 视频发布（或图文/文章）→ 批量发布并看进度 → 发布历史查结果。中途可随时存草稿。

## 3. 其余核心菜单功能与引导设计（✅ 均已实现）

### 3.1 素材管理

**作用**：视频/图片素材的统一仓库，发布页取材都来自这里。扁平库，无文件夹；支持本地/S3 双存储。

**功能清单**：上传（拖拽/点选，单次 ≤20 个，单文件不限大小，>100MB 自动分片断点续传）；按文件名搜索；类型筛选（全部/图片/视频）；卡片（缩略图、大小、时间、本地/S3 徽章、视频播放预览、悬浮删除）；批量删除（勾选模式）；分页（12/24/48/96）。视频上传后自动抽帧缩略图、探测时长/宽高。

**引导建议（8 步）**：① 欢迎页（素材库=统一仓库）→ ② 上传按钮 → ③ 搜索框 → ④ 类型筛选 → ⑤ 素材卡片墙（空库时文案「上传后素材会显示在这里」）→ ⑥ 卡片悬浮操作（预览/删除）→ ⑦ 批量整理 → ⑧ 分页与刷新 + 引导去发布页。需补 `data-tour`：`material-upload / material-search / material-type-filter / material-grid / material-card-preview / material-batch / material-pagination`。

### 3.2 视频发布（核心页）

**作用**：多平台多账号视频批量发布。左=账号栏，顶=视频队列，中=公共配置+平台设置，右=手机预览。

**关键流程（4 步）**：
1. **选账号**：左下「+ 账号设置」→ 弹窗三栏（渠道筛选/账号网格/标签筛选）勾选；
2. **加视频**：队列「+ 添加视频」（素材库多选/本地上传）；新视频自动继承当前配置、自动抽帧生成 4 比例封面、标题自动填文件名；
3. **填内容**：标题/描述/标签（`#话题` 自动提取）+ 平台专属字段（创作声明必填项、合集、热点、位置、定时 ≤14 天等）+ 两级个性化（渠道覆写/账号覆写，合并优先级：账号 > 平台覆写 > 平台默认 > 公共）；
4. **发布**：批量发布 → 前端体检（缺封面/超字数/漏声明会内联提示）→ Cookie 预检（失效自动重登）→ 确认弹窗（设发布间隔，默认 30 分钟防风控）→ 后端任务队列异步执行 → 实时进度弹窗（逐账号状态/倒计时/单个取消/成功链接，可后台运行）。

**提效工具**：一键填写（套历史模板）、批量设置（铺标签/声明到多渠道甚至全队列）、保存草稿（v2 整队列快照，自动保存）。

**引导建议（9 步）**：① 先选账号 → ② 挑选账号（弹窗三栏）→ ③ 添加视频（队列）→ ④ 手机预览 → ⑤ 封面（自动裁剪+时间轴编辑）→ ⑥ 标题与内容 → ⑦ 平台专属设置（红字警告必看）→ ⑧ 定时发布 → ⑨ 批量发布与进度。需补 `data-tour`：AccountSidebar 的 `account-setting-btn`、VideoQueueBar 的 `queue-add`、PublishCenter 的 `platform-settings`/`cover-grid`/`field-scheduleTime`（settingsFields 循环渲染用 `:data-tour="'field-' + field.key"`）。

### 3.3 图文发布（图集发布）

**作用**：6 平台（小红书/抖音/快手/微博/支付宝/公众号）图集发布。结构与视频发布同构（左账号栏 + 顶栏 + 公共配置 + 平台面板 + 手机预览）。

**关键差异**：图片最多 35 张，支持拖拽上传与拖柄排序；封面可选；平台面板各有限额与特色（抖音官方活动/音乐/热点/POI 标签/合集、小红书原创声明+定时、快手音乐+声明、微博无标题仅正文、支付宝音乐抽屉、公众号合集+定时）；顶栏多「一键填写」「批量设置」；右侧「放大预览」支持缩放旋转。

**引导建议（8 步）**：① 添加账号 → ② 展开分组选中账号 → ③ 上传图片（点选/拖拽）→ ④ 封面 → ⑤ 平台内容（标题必填、#话题）→ ⑥ 手机实时预览 → ⑦ 批量与草稿 → ⑧ 一键发布。需补 `data-tour`：`platform-panel`（第二个 config-section）、`btn-save-draft / btn-one-click-fill / btn-batch-set`。

### 3.4 文章发布

**作用**：7 平台（公众号/知乎/CSDN/微博/百家号/大鱼号/头条）长文章发布。标题+富文本正文全局公共，右侧手机实时预览。

**关键能力**：自研富文本（标题层级/加粗/列表/引用/分割线/图片上传+素材库选图，粘贴纯文本自动转段落）；封面横竖版各 2 比例可裁剪，不设则自动抓正文首图；每平台差异化设置（公众号原创声明/留言/摘要/定时、知乎话题≤3/内容来源联动、CSDN 标签必填 1~6/转载联动、微博导语≤44、头条首发/微头条/投放广告、大鱼号信息来源必选等）；发布模式=存草稿箱（默认安全）/直接发表（公众号群发需扫码）。

**引导建议（9 步）**：① 欢迎 → ② 添加发布账号 → ③ 标题 → ④ 富文本正文 → ⑤ 封面 → ⑥ 平台个性化设置 → ⑦ 发布方式（存草稿箱 vs 直接发表）→ ⑧ 保存草稿 → ⑨ 一键发布（+右侧预览彩蛋）。需补 `data-tour`：`title-input / rich-editor / platform-settings / save-draft`、CoverCard 两卡 `cover-landscape / cover-portrait`。

### 3.5 草稿箱

**作用**：视频/图集/文章三类草稿集中管理。草稿=发布页完整状态快照；三个发布页均有「保存草稿」+ 开启设置后自动保存。

**功能**：三类 tab（带数量徽标）；卡片（封面/标题/目标平台×账号数/时间）；「编辑」带参跳回发布页恢复全部内容（保存按钮变「更新草稿」）；单删/批量删除（1~30 个）；批量发布：视频→后端任务队列（逐草稿×账号校验合并入队，最多 30）、图集→同步逐条发布、文章→推送公众号草稿箱；空状态一键去发布。

**引导建议（5 步）**：① 认识草稿箱 → ② 三类 tab 切换 → ③ 认识草稿卡片 → ④ 编辑/删除 → ⑤ 多选批量操作。需补 `data-tour`：`draft-tabs / draft-card / card-edit / draft-toolbar`；空列表时第 3/4 步自动跳过。

### 3.6 系统设置

**作用**：应用偏好。单页滚动 + 7 张卡片；**所有修改需点底部「保存设置」才生效**。

| 卡片 | 内容 | 新手须知 |
|---|---|---|
| 网络代理 | HTTP 代理地址 | 仅发 YouTube/TikTok 需要，国内平台留空 |

| 缓存管理 | 抽帧/日志/S3 视频缓存/封面缓存一键清理 | 磁盘紧张时用 |
| 技术栈 | 版本/数据目录（只读） | — |
| 反馈系统 | 反馈邮箱（「一键反馈」必需） | 想反馈时填 |

**引导建议（7 步）**：① 欢迎（强调要保存）→ ② 海外代理 → ③ 发布自动化开关 → ④ 账号检查时机 → ⑤ 渠道黑名单 → ⑥ 文件存储 → ⑦ 别忘了保存（`.save-btn`）。需补 `data-tour`：`card-proxy / card-publish / check-mode / blacklist-add / storage-type`。

### 3.7 辅助页面

## 4. 新手引导实现架构（供其余页面接入）

```
src/components/GuideTour.vue   通用引导引擎（零依赖）：全屏遮罩 + box-shadow 聚光挖孔 + 自适应定位气泡
                               （8 方位回退/箭头/步骤徽标/进度点/上一步·下一步·跳过/Esc←→ 键盘/滚动缩放跟随/缺失目标自动跳过）
src/config/guides.js           各页面步骤配置 + localStorage 完成态（GUIDE_KEYS / isGuideDone / markGuideDone / resetGuide）
页面接入三件事：
  1) 在 template 关键元素上加 data-tour="xxx" 锚点（比 class 稳，抗重构）
  2) <GuideTour ref="guideTourRef" :steps="xxxGuideSteps" @finish="onGuideDone" @skip="onGuideDone" />
  3) onMounted 里 isGuideDone(KEY) 为 false 时延时 600ms 自动 start()；页头放一个「新手引导」重看按钮
步骤字段：target / title / content / icon / placement / skipIfMissing
```

**约定**：气泡文案 ≤60 字、口语化、说清"这是什么+点它会怎样"；条件渲染元素一律 `skipIfMissing: true`；弹窗内部元素不进静态引导（未打开时不在 DOM）。

## 5. 调研中发现的已知问题（引导设计与后续修复参考）

1. 素材管理页搜索无防抖（每键一次请求），选择弹窗有 300ms 防抖——行为不一致。
2. 素材管理页图片素材无预览入口（仅视频可预览），预览弹窗图片分支是死路径。
3. 草稿箱：文章 tab 卡片不支持多选勾选（工具栏却全局共享）。
4. 草稿箱批量发布图集：后端仍查旧表 `image_drafts`，而生产已写统一 `drafts` 表，该链路大概率 404，建议验证修复。
5. 文章发布 `hasAccountOverride` 只查公众号面板，其他 6 平台的账号覆盖不显示 ⭐ 标记。
6. 设置页技术栈版本为前端硬编码，非动态读取。
7. `stores/app.js` 的 `isFirstTimeAccountManagement` / `isFirstTimeMaterialManagement` 为无消费者的遗留标志（与本次引导的 localStorage 机制互不影响）。
